# Security

This script does not store or need any passwords. MailStore Home keeps your
mailbox credentials inside its own profiles.

If you share log files or a copy of your configured script (for example in an
issue), remove any email addresses, server names, and file paths you do not
want to make public first.

If you find a security problem in the script, please open an issue without
sensitive details, or contact the maintainer through GitHub.
